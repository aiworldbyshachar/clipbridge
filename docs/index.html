Small app. Everything you need.

One shared history, no limit

Everything you copy on either computer lands in one history, with the device it came from. Search it, star what matters, click to copy it again. Open it any time with Ctrl+Shift+Space (⌘⇧Space on Mac).

Private by design

No account, no server, no cloud. Your computers talk directly on your own network, and everything between them is encrypted (AES-256-GCM) with a key made from your connection code.

  • Private mode pauses everything with one click — handy while copying passwords.
  • It also tries to skip content that password managers mark as private.

Text, formatting and images

Plain text, formatted text (it keeps its formatting when you paste) and images such as screenshots.

Speaks your language

English, עברית, Español, Français, Русский and العربية — with full right-to-left layouts for Hebrew and Arabic.

Install

ClipBridge isn't signed with paid Apple/Microsoft certificates, so both systems ask once before opening it.

Windows

  1. Run ClipBridge-Windows-Setup.exe.
  2. If you see “Windows protected your PC”, click More info → Run anyway.
  3. When the firewall asks, click Allow access, and make sure your home network is set to Private.

Mac

  1. Open ClipBridge-macOS.dmg and drag ClipBridge into Applications.
  2. Open it once. If macOS says it can't verify it, go to System Settings → Privacy & Security and click Open Anyway.
  3. Allow ClipBridge to find devices on your local network when asked.
If macOS says the app “is damaged”, run this once in Terminal:xattr -cr /Applications/ClipBridge.app

Questions

Does it work when my computers are on different networks?

No — that's the point: everything stays on your local network. When you come back to the same Wi-Fi, anything copied in the meantime syncs into the shared history.

Where is my history stored?

On each computer, in the app's data folder (Settings → Open data folder). Clearing the history clears it on all connected devices, except starred items.

The other computer doesn't show up.

Check that both are on the same network (not a guest network), that ClipBridge is open on both, and that the codes match. If your router blocks discovery, add the other computer by its IP address in Settings → “Other device not showing up?”.

Can it sync files?

Not yet — text, formatted text and images. Contributions are welcome.

Is it really free?

Yes. ClipBridge is open source under the MIT licence. No accounts, no ads, no tracking.
